# 踩坑记录

按踩到的顺序记，重点写「症状 → 真因 → 处理」。

## 1. 节点树是空的

**症状**：`uiautomator dump` 拿到的 XML 里只有系统窗口，微信界面一片空白；
各类读屏自动化工具读到的东西也一样。

**真因**：微信对无障碍节点树做了限制，不是你的环境有问题。

**处理**：放弃节点树，改用 `adb shell input` 注入原始触摸事件，
文字走输入法层（ADB Keyboard）注入。这条路径不经过无障碍层。

## 2. 注入文字没反应，误判成「微信拦截了注入」

**症状**：`input text` / `am broadcast` 执行成功、无报错，但输入框里什么也没有。

**真因**：焦点根本没在输入框上。1080×2400 的微信聊天页，输入框中心大约在
`y=2150`；当时按 `2127` 点，差了二十多像素，点在输入框上沿的分隔线上。
**没拿到焦点，注入自然落到别处或直接丢掉。**

**处理**：先点准，再注入。用 `screencap` 截图 + PIL 分析，或者小范围试几个
y 值确认。差几十像素就足以让整个判断跑偏，别急着怀疑 App 拦截。

## 3. 文字打进了别的 App

**症状**：本来想打进微信，结果出现在自己的编辑器 / 浏览器地址栏里。

**真因**：切前台失败或者根本没切，`input` 是全局的，谁在前台就打给谁。

**处理**：每次注入前先 `dumpsys window | grep mCurrentFocus` 确认包名。
本项目里就是 `scripts/check-focus.sh` 和 `scripts/lib.sh` 的 `require_focus`。

## 4. 发送按钮偶发点不灵

**症状**：消息输进去了，点发送按钮有时没反应，有时点到了表情面板。

**真因**：按钮命中区小，且键盘弹出/收起时布局会抖动。

**处理**：不要点按钮，用输入法的发送动作：

```bash
adb shell am broadcast -a ADB_EDITOR_CODE --ei code 4
```

`code 4` 是 `IME_ACTION_SEND`。这条在微信里比坐标点击稳定得多。

## 5. 中文被 shell 拆坏

**症状**：只发出去了第一个词，或者报 `Unable to parse`。

**真因**：`am broadcast` 的参数里有空格和中文，没整体加引号。

**处理**：

```bash
adb shell "am broadcast -a ADB_INPUT_TEXT --es msg '中文内容'"
```

整个命令用双引号包住。长文本改用 `ADB_INPUT_B64` + base64，避免特殊字符。

## 6. 用完输入法没切回去

**症状**：用户自己打字时中文键盘没了。

**真因**：为了注入把默认输入法切成了 ADB Keyboard，结束没切回。

**处理**：`scripts/restore-ime.sh`，务必放在流程最后。原输入法包名按机型不同，
用 `DEFAULT_IME` 环境变量覆盖，默认值是百度输入法小米版。

## 7. 无线调试端口每次开机都变

**症状**：昨天 `adb connect` 还好，今天连不上。

**真因**：无线调试的端口（有时连 IP）在重启或重开无线调试后都会变。

**处理**：每次连之前去 设置 → 开发者选项 → 无线调试 看当前端口。
`scripts/connect.sh` 会把上次成功的地址记到 `~/.android/last-endpoint.txt`，
但那只用于「先试一下」，不是可靠来源。

## 8. 装 ADB Keyboard 报 INSTALL_FAILED_USER_RESTRICTED

**真因**：开发者选项里的「USB 安装」没开。

**处理**：打开后再装。

## 9. 锁屏 / 后台时注入

**症状**：命令都成功，但醒来发现什么都没发生，或者打进了解锁密码框。

**处理**：注入前检查前台包名和 `mInputShown`。锁屏状态下永远不要注入。

## 10. 用 adb 截图看状态

节点树被屏蔽不代表没法看界面：

```bash
adb shell screencap -p /sdcard/Download/x.png
adb pull /sdcard/Download/x.png .
```

配合人眼看图判断当前在哪个页面，比猜坐标可靠。用完记得删掉截图。

## 通用建议

- 每一步之间留一点 `sleep`（0.3–0.6 秒），UI 动画没走完就点会点空
- 坐标和包名做成变量或参数，不要散落在脚本里
- 先在小号 / 测试会话上跑通流程，再动真实会话
